# Ветеринарна клиника

Уеб приложение за управление на ветеринарна клиника: профили на собственици и домашни любимци, записване на часове при ветеринарни лекари според тяхното работно време и електронно досие на всяко животно (прегледи, диагнози, медикаменти и ваксинации).

## Цел

Да се улесни работата на клиниката и комуникацията със собствениците: собственикът записва и отменя часове онлайн и вижда досието на своя любимец, ветеринарният лекар попълва прегледите и ваксинациите, а администраторът управлява лекарите, графиците и номенклатурите.

## Технологии

- ASP.NET Core MVC (.NET 10) с Razor изгледи, HTML5, CSS3, JavaScript, Bootstrap
- ASP.NET Core Identity – регистрация, вход, роли, защитени бисквитки
- Entity Framework Core 10 (Code First, миграции)
- Microsoft SQL Server
- xUnit – тестове

## Архитектура

Многослойно решение (шаблон Service Layer):

| Проект | Отговорност |
| --- | --- |
| `src/VetClinic.Web` | MVC контролери, изгледи, Identity страници, конфигурация |
| `src/VetClinic.Services` | Бизнес логика (записване на часове, ваксинационен календар и др.) |
| `src/VetClinic.Data` | Същности, `VetClinicDbContext`, конфигурации и миграции |
| `tests/VetClinic.Data.Tests` | Тестове на модела на базата данни |
| `tests/VetClinic.Services.Tests` | Тестове на бизнес логиката |

## Модел на данните

Основни същности: `ApplicationUser`, `Veterinarian`, `WorkSchedule`, `Species`, `Pet`, `Appointment`, `Examination`, `Medication`, `Prescription`, `Vaccine`, `Vaccination`.

## Роли

- **Owner** (собственик) – управлява своите любимци, записва и отменя часове, вижда досиетата им
- **Vet** (ветеринарен лекар) – вижда своя график, попълва прегледи, рецепти и ваксинации
- **Admin** (администратор) – управлява лекари, графици, номенклатури и статистики
- **Гост** – разглежда публичната информация, може да се регистрира

## Стартиране локално

Изисквания: .NET 10 SDK и SQL Server (напр. LocalDB).

1. Връзката към базата данни се пази в User Secrets, а не в `appsettings.json`:

   ```bash
   dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=(localdb)\MSSQLLocalDB;Database=VetClinicDb;Trusted_Connection=True;MultipleActiveResultSets=true;TrustServerCertificate=True" --project src/VetClinic.Web
   ```

2. Създаване на базата данни:

   ```bash
   dotnet tool restore
   dotnet ef database update --project src/VetClinic.Data --startup-project src/VetClinic.Web
   ```

3. Стартиране:

   ```bash
   dotnet run --project src/VetClinic.Web
   ```

4. Тестове:

   ```bash
   dotnet test
   ```

## Планирани функционалности

- роли и демо акаунти, начални номенклатури (видове животни, ваксини, медикаменти)
- профили на собственици и домашни любимци
- записване и отменяне на часове според свободното време на лекарите
- електронно досие: прегледи, диагнози, рецепти, ваксинации
- автоматично изчисляване на датата на следващата ваксина
- управление на лекари, графици и номенклатури от администратор
- статистики и известия по имейл
- адаптивен интерфейс, клиентска и сървърна валидация, собствени страници за грешки
- unit и интеграционни тестове (покритие поне 65%), тестове за SQL injection и XSS
- CI/CD и публичен адрес с демо акаунти
